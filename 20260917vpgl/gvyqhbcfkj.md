# 【幼儿科普】鼻通仍口呼吸？三个训练帮娃改

> 更新时间：2026-09-17 (UTC+8)

**习惯·训练·耐力**

**鼻通仍口呼吸**

**三个训练帮娃改**

5岁的朵朵刚做完扁桃体腺样体切除术，困扰已久的鼻塞问题终于解决——医生检查确认，她的鼻腔通道已完全通畅，无需再为呼吸费力。可让妈妈纳闷的是，晚上睡觉的朵朵依旧张着小嘴，呼噜声虽轻了，但口呼吸的习惯却没改掉。这到底是怎么回事？

不是鼻子“不听话”

是肌肉“记旧习”

很多家长都和朵朵妈妈有同样的困惑：明明手术成功、鼻子能正常通气，孩子怎么还改不了口呼吸？其实答案很简单——长期口呼吸让孩子口唇周围的肌肉“变懒了”。

就像习惯用右手写字后，左手难熟练握笔一样，孩子长期张口呼吸时，嘴唇和面部肌肉会逐渐失去收缩力量。即便鼻子通畅了，肌肉也会“惯性”保持张口状态，尤其睡眠时，口呼吸自然成了“默认模式”。不过家长不用急，通过针对性肌肉训练，帮孩子重建鼻呼吸习惯，问题就能慢慢改善。

三个简单动作

在家就能练

针对口唇肌肉力量不足，医生推荐3个超简单训练动作，每天花10分钟坚持练，几周后就能见明显效果：

1.用力抿唇“攒力气”

让孩子像吹蜡烛般，用力抿紧嘴唇保持10秒后放松，每组10次、每天3组。这个动作能直接锻炼嘴唇闭合肌肉，增强收缩力，让孩子睡眠时能自然闭嘴。

2. 纸片“小考验”

准备一张轻薄纸片（如便利贴撕成的小条），让孩子用双唇轻轻夹住，保持不掉落并坚持3分钟。练习时让孩子正常用鼻呼吸，能训练嘴唇控制能力，让闭合成为肌肉记忆。

3. 鼓腮“练耐力”

让孩子像吹气球般，把气体鼓到两侧腮帮，抿紧嘴唇不泄气，保持2秒后慢慢呼气，每组10次、每天至少3组。既能锻炼面部肌肉，还能提升呼吸协调性，帮孩子养成用鼻深呼吸的习惯。

提醒家长，肌肉训练需要耐心，别指望一两天见效。建议每天固定时间和孩子一起练，把训练变成亲子互动，孩子更容易坚持。若练习1-2个月后，口呼吸习惯仍未改善，建议带孩子复诊，让医生评估是否需要进一步干预。

孩子的鼻呼吸习惯越早纠正，越能避免面部发育受影响，还能减少口腔干燥、呼吸道感染等问题。跟着这3个小动作练起来，帮孩子彻底和口呼吸说再见。
